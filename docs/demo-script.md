# Phase 1 demo

1. Open the local Angular app. Point out the synthetic-data badge and the snapshot date.
2. Show all 36 state/UT tiles. Explain that each has fictional facilities and sampled districts.
3. Open Maharashtra, then Pune from the district selector. All headline numbers and tables now use Pune only.
4. Open a facility. Reconcile an inventory row, inspect bed availability and staff attendance.
5. Show the 28-day demand history. Explicitly call it synthetic observations, not a forecast.
6. Open Medicine & supply. Show the facility count below the seven-day reserve.
7. Open Early warnings. Show the rule calculation and operational action.
8. Return to All India and open another state or UT to demonstrate nationwide scope.
9. Open Data & project scope to show implemented features and later milestones.

The later full demo will add the Pune dengue surge, measured model forecasts, OR-Tools transfers, a grounded Gemini explanation and an Indian state-node federated round. None should be represented as implemented yet.
