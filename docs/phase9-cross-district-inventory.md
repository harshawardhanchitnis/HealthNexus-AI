# Phase 9 optimizer inventory (before implementation)

Baseline: `723c6a8`, clean working tree. Phase 6 is closed; this phase sends zero Gemini requests. Saved Phase 6 evidence, ledger, `.env`, model/planning assets, federation and authoritative forecasting/warning/scenario code are fingerprinted in the local preservation receipt.

The existing request supports district, state and national donor scope. Navigation geography selects receivers independently. `_prepare` discovers baseline donors in the district, entire selected state, or country respectively. Scenario projections replace only affected facilities, leaving other donors on their own baseline demand. State mode therefore has latent multi-district capability, but includes same-district donors: it is **not** a strict different-district mode. National mode remains domestic.

`candidates.protection` takes the minimum raw balance over origin, point forecast and all 500 paired sampled demand paths, every day of the 14-day horizon, using known receipts. The reserve is ceil(safety stock × 1) + 1. Origin stock must additionally retain at least seven days of mean point-demand cover. Transferable surplus is the floor of the smallest protected margin. Receivers need enough origin receipts to meet reserve/current-cover targets. No reserve or path policy will change.

Edges currently match resource codes and geography; their unit labels come from projection/candidate objects. Explicit unit compatibility will be checked as an additional association guard. Facilities already have validated, deterministic latitude/longitude. These fictional facility coordinates will be reused unchanged; no geocoding or coordinate regeneration is necessary. Distance is Haversine, rounded only for the existing unit-cost formula. It is neither road distance nor travel time.

CP-SAT minimizes critical unresolved units, then weighted unresolved units, then transport cost (distance, geographic penalty, donor risk and active-lane penalty), fixing each proven optimum before the next stage. Seed 42 and one worker are unchanged. Greedy uses the identical candidate/edge/capacity network. The paired post-transfer simulation conserves resources, checks reserve and non-negative stock, and rejects increased donor risks, unmet demand or safety breaches. All 500 paths remain protected. Plans are independent advisory alternatives applied at origin in simulation, never executed shipments.

The action-state adapter is in the frozen AI layer: advisory, physical_execution=false, externally_authorized=false, hospital_contacted=false, not_executed. Phase 9 will expose the same explicit semantics in its new read-only geography contract without editing that adapter.

Optimization APIs use the same service for preview, run and saved results; saved results are country/profile scoped and process-local. Frontend donor scope currently has district/state/national controls, defaults to district for a selected district, but is not independently persisted in the URL. Saved-plan context checks geography/profile/scenario. Additive strict `cross_district` will require India, receiver state and district, discover the state network and exclude the receiver district from donor eligibility. Existing district filtering, safety mathematics, solver objective and canonical values stay unchanged.

The geospatial read model will use original facility geometry and operational summaries, existing forecast/scenario/warning projections, and actual stored optimization lanes. It will reject stale/mismatched overlay handles before returning GeoJSON. MapLibre sources/layers will visualize these objects; the map will not calculate risks or become a planning dependency.
